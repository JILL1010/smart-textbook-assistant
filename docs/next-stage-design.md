# 下一阶段设计与实施记录

## 已确认的方向

2026-10-08，用户确认：

- 主要目标：自己长期使用。
- 辅助目标：作品展示和 NLP 实验。
- 分工：助手负责实现，用户负责使用和验收。
- 不根据用户投入时间制定开发排期。
- 实施顺序：A（可核对来源的问答）→ C（持久化学习记录）→ B（完整章节讲解）。三个阶段均在目标范围内，按此顺序推进。

## 实施前事实

- 第一轮可靠性修复及验证已完成，边界见 `reliability-checks.md`。
- 章节问答仍只读取原文前 6000 个字符，返回结果没有引用来源。
- 当前章节模型没有保存原文页码或段落来源；解析时使用过的 PDF 页码在合并章节内容时丢失。
- 练习题会保存，作答选择和分数仍仅存在于页面内存。

## 已确认的实施顺序

1. **A：可核对来源的问答。** 覆盖章节后半部分的内容，回答附有原文来源。
2. **C：持久化学习记录。** 保存作答、错题和复习记录，支持后续继续学习。
3. **B：完整章节讲解。** 覆盖长章节全文，组织成有层次的学习内容。

## A 阶段已确认边界

- 检索范围：优先当前章节，并允许查找同一本课本的其他章节；不混入其他课本。
- 回答边界：教材为主，允许明确标注的补充解释。教材依据不足必须明确说明，补充解释不能冒充原文或使用虚构引用。

实现范围：继续支持已有的文字 PDF / DOCX，保留原文位置并实现检索和引用；扫描件 OCR、跨课本检索和联网搜索留作后续扩展。助手负责工程方案与自动化验证。

## 实施结果（2026-10-08）

按 A → C → B 完成实现：

- A：同书全文片段检索、当前章加权、PDF 页码 / DOCX 段落来源、来源页面，以及教材回答和补充说明的分区。
- C：数据库保存已读标记、作答草稿、成绩快照、错题和复习次数；重新生成保留历史学习记录。
- B：长章节按原文顺序分段生成，各部分完整传入模型；记录难度、风格、字符数和分段数，整次成功后才保存。

具体使用方式、验证结果和仍存在的边界见 `learning-features.md`。真实模型生成质量和真实语音同步仍需配置服务后验收。

术语见根目录 `CONTEXT.md`。仅在出现有实际替代方案、未来变更成本较高的重要决定时添加 ADR。
