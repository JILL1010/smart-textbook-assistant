# 教材问答、学习记录与整章讲解

2026-10-08，按用户确认的 A → C → B 顺序实现。开发启动方式见 `reliability-checks.md`。

## A：可核对来源的问答

在章节底部提问。系统将同一本课本的原文切成有重叠的片段，用词项匹配排序，并对当前章节加权，取最多 6 个片段。章节后半部分和同书其他章节均参与检索，不读取其他课本。

回答分为“教材依据”和“补充说明”。引用展开后显示原文，可点击“查看原文位置”，再打开原始 PDF 的相应文件页。DOCX 使用文档段落编号。页码按 PDF 文件页序计算，与书上印刷页码可能不同。

新导入教材直接保留来源位置。旧教材只有在原文能唯一匹配到原始文件时才恢复位置，否则明确标记“原始页码未恢复”。未配置模型时仅展示检索原文；模型无依据时明确说明，返回未提供的引用 ID 时拒绝保存回答。

目前是词项检索，未加入语义向量、OCR 或联网搜索。引用 ID 可核验不代表模型的每个推论都正确，仍需阅读对应原文。

## C：持续学习与错题复习

- “标记本章已读完”保存到数据库，刷新和重启后保留。
- 练习选择停留 400 毫秒后自动保存，显示保存状态。离开前等待“作答已保存”。
- 提交后由后端评分，保存题目、答案、成绩和讲解版本；页面展示最近 20 次记录。
- 课本或章节中的错题本入口支持再次作答，记录复习次数，答对后标记已复习。

重新生成讲解会清空当前练习、音频和图谱，但保留旧成绩与错题快照。旧题的迟到作答请求会被拒绝；较旧的自动保存请求不会覆盖较新的草稿。删除课本会同时删除其学习记录。目前没有定时复习通知或间隔复习调度。

## B：长章节完整处理

讲解原文按最多 6500 字符分段，优先在段落边界切分，每个字符进入一个片段。各部分依次生成并按原文顺序合并；页面保存并显示难度、风格、原文字数和分段数。

超过 40 段时明确拒绝生成；任意一段失败、为空或模型因长度截断时，已有讲解不被覆盖。多段章节会产生多次模型请求。未配置模型时显示完整原文模板，并明确标记模板模式。

全文传入不等于真实模型一定完整讲清所有知识。练习和图谱目前仍使用讲解前 8000 字符，尚未扩展为全文题目覆盖。
