# 持久化生成任务

讲解、练习和知识图谱通过后台任务生成。启动接口返回 HTTP 202 和任务 ID，页面每秒读取状态；刷新或离开页面不停止生成。任务保存在 SQLite，接口不返回任务中保存的原文快照。

## 使用与恢复

- 任务面板显示排队、生成中、完成、失败、停止或中断，以及已完成的分段数。
- 本地只有一个生成工作线程；不同章节的任务排队执行。同一章节只允许一个活动任务，重复启动同类型任务返回已有任务。
- 停止排队任务立即生效。已发出的模型请求不能撤回；停止运行任务会等待该请求返回，随后不再处理下一段，也不发布结果。模型请求默认超时 90 秒，可用 `LLM_TIMEOUT_SECONDS` 调整。
- 失败、停止或服务重启后的中断任务可从头重试，不复用已生成的部分。章节版本变化后必须重新生成。
- 任意一段失败时保留旧讲解和派生内容。成功结果与任务完成状态一起提交；生成期间章节被修改或课本被删除时，迟到结果不会覆盖数据。

## 部署约束

当前面向单机个人使用，FastAPI 必须运行一个进程，不使用 `uvicorn --workers` 多进程。启动和关闭时将未完成任务标记为中断，不自动继续或重新计费。音频生成仍使用原来的请求流程。

任务保存原文快照，数据库属于私人学习数据。删除课本会删除其任务。界面展示最近 5 条，列表接口返回最近 20 条；当前没有自动清理历史任务。

## 接口与检查

基础路径：`/api/textbooks/{book}/chapters/{chapter}/tasks`。

- `GET`：读取任务；`POST`：以 `kind=lecture|quiz|graph` 启动。
- `POST /{task_id}/cancel`：请求停止。
- `POST /{task_id}/retry`：从头重试。

`apps/api/tests/test_tasks.py` 覆盖进度、去重、取消、失败与重试、版本冲突、删除、重启中断和事务发布。浏览器脚本检查进度刷新恢复、停止保留旧内容，以及重试完成后的练习和图谱。
