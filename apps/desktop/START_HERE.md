# Windows 桌面版使用说明

1. 将整个 ZIP 解压到一个可写的新目录，保留 `node.exe` 和 `_internal/` 等全部文件。
2. 双击 `智能课本助手.exe`，程序会启动本地服务并打开浏览器；关闭启动窗口退出。
3. 不配置模型时，可体验原文检索与完整原文模板。使用真实模型时，在 EXE 旁将 `.env.example` 复制为 `.env`，填写自己的接口地址、模型和 API 密钥，然后重启。
4. 首次启动创建空教材库。数据库、教材和音频保存在 EXE 旁的 `data/` 和 `uploads/`。如需继续旧教材库，先备份旧目录，再将其 `data/` 和 `uploads/` 一起复制到新目录。

讲解、练习与图谱在后台生成；刷新页面不停止任务。运行中的停止操作会等待当前模型请求返回，重试从头开始。服务重启后任务标记为中断，需要手动重试。

模型讲解和题目需要核对原文。真实验收发现中文检索英文教材能力不足，以及数学算例、矩阵维度和条件缺失问题。配置 `LLM_REASONING_EFFORT=none` 能改变支持该参数的模型的生成模式，但不保证数学正确性。

该包面向本地个人使用，不含个人 API 密钥、教材或学习记录。开源代码与质量记录：<https://github.com/JILL1010/smart-textbook-assistant>。许可证见 `LICENSE`、`licenses/` 和各依赖目录中的许可文件；准确源码版本见 `BUILD_INFO.json`。
